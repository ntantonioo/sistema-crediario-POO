# sistema-crediario-POO
Sistema de Vendas de Crediário

Mini sistema desenvolvido em Java para gerenciar vendas a crediário (venda parcelada com controle de limite de crédito por cliente).

O sistema permite:

- Cadastrar, pesquisar e remover Vendedores.
- Cadastrar, pesquisar e remover Clientes.
- Cadastrar, pesquisar e remover Vendas, vinculando um Cliente e um Vendedor.
- Verificar automaticamente se o cliente possui limite de crédito disponível antes de concluir uma venda (caso contrário, uma exceção é lançada).
- Consultar vendas por cliente e por vendedor.
- Calcular o total vendido por um vendedor.
- Listar clientes que ainda possuem limite de crédito disponível.
- Salvar e recuperar todos os dados do sistema em arquivo.
